# Category Images

This directory should contain images for journey categories. Each category needs an image file:

- entertainment.jpg - Movies, concerts, shows, performances
- shopping.jpg - Malls, stores, retail therapy
- dining.jpg - Restaurants, cafes, culinary experiences
- outdoor.jpg - Hiking, parks, nature activities
- sports.jpg - Sports events, fitness, workouts
- travel.jpg - Sightseeing, tourism, destinations
- social.jpg - Meetups, parties, gatherings
- education.jpg - Workshops, classes, learning
- wellness.jpg - Spa, yoga, relaxation
- arts.jpg - Museums, galleries, culture
- nightlife.jpg - Bars, clubs, evening entertainment
- volunteer.jpg - Community service, charity work

Images should be:
- High quality and representative of the category
- Optimized for web use (max 500KB each)
- Consistent style and aspect ratio
- At least 800x600 pixels resolution

You can use stock photos or create custom images that match your app's theme.
